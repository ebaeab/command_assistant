# 命令助手

基于 Node.js + Ink 的终端命令执行应用。

## 功能特性

- **命令输入**: 直接输入并执行本地命令
- **常用命令**: 预设常用命令按钮，快速执行
- **回显输出**: 实时显示命令执行输出，支持滚动
- **历史记录**: 自动保存历史命令，可重复执行或编辑
- **保存常用命令**: 从历史记录中保存命令到常用命令
- **持久化存储**: 命令历史和常用命令自动保存到 `~/.ink-term/history.json`
- **中文支持**: 正确处理 Windows 中文编码 (GBK)

## 快速开始

### 开发模式

```bash
npm install
npm run dev
```

### 打包安装

```bash
npm install
npm run build
npm start
```

## 按键说明

### 全局
- `Tab` 或 `1`/`2`/`3`: 切换面板
- `Ctrl+C`: 退出应用

### 输入面板
- `Enter`: 执行命令

### 常用命令面板
- `↑/↓` 或 `j/k`: 上下选择
- `Enter`: 执行选中命令
- `d`: 删除选中的常用命令

### 历史记录面板
- `↑/↓` 或 `j/k`: 上下选择
- `Enter`: 执行选中命令
- `e`: 将选中命令加载到输入框编辑
- `s`: 将选中命令保存到常用命令

### 输出面板
- `PgUp/PgDn`: 滚动输出内容

## 面板说明

### 输入
直接输入命令并按 Enter 执行。

### 常用命令
预设常用命令（默认：adb devices、ipconfig），可从历史记录添加新命令，也可删除不需要的命令。

### 历史
显示最近执行的命令记录，可以重新执行、编辑或保存为常用命令。

## 配置文件

命令历史和常用命令保存在 `~/.ink-term/history.json`。

## 构建命令

```bash
npm run build      # 编译 TypeScript
npm start          # 运行编译后的代码
npm run dev        # 开发模式运行
```
